# Godot 版畫面升級：重新規劃（2026-10-22）

> **專案目標（使用者指定）：以網頁 v2 版為基礎，大幅提升畫面品質。**

> 背景：Godot 版（`godot/`，4.7、D3D12＋Forward+）玩法已大致移植完成（飛行員、自由與劇本模式、四語、斷裂），但「畫面大幅超越網頁版 v2」這個主目標卡住了。這份文件先診斷卡在哪，再給新的做法與順序。
> 前一份規劃：`ENGINE-MIGRATION-PLAN.md`（引擎選擇與階段 1~4）；美術基準：`VISUAL-REFERENCE-SQ42.md`。

---

## 1. 診斷：為什麼越做越卡

### 1.1「DX12」本身不會讓畫面變好
D3D12 是顯示卡的「溝通方式」（API），不是畫質。Godot 用 D3D12 或 Vulkan，畫出來的圖幾乎一樣；它帶來的是**效能空間**（階段 1 已證實：2400 艘仍 70+ fps）。畫面要變好，得把這些空間**花在對的地方**——到目前為止，空間大多花在爆炸粒子與 POM，而不是決定畫面質感的那幾件事。

### 1.2 畫面質感的四根柱子，目前狀態
| 柱子 | 對畫面的影響 | 目前狀態（查過程式碼與模型） |
|---|---|---|
| **光照** | 最大 | 主光 `shadow_enabled = false`、所有艦 `cast_shadow = OFF` → **沒有任何陰影**，艦體互相不遮光，所以看起來「平、塑膠、浮在空中」。環境光只有天空 ×0.2，沒有反射探針 → 金屬沒有東西可以反射，所以不像金屬。 |
| **資產（模型＋材質）** | 很大，而且是**天花板** | 主力艦 GLB 多半只有一張底色貼圖（1024~2048），**沒有法線圖、沒有金屬度／粗糙度圖**（cruiser、ipc、fighter 都是；只有 hss 有法線）。底色還是為網頁版「無色調映射」提亮過的，進 ACES 就過曝。POM 是從底色「猜」出高度，所以看起來僵。 |
| **特效** | 中 | 爆炸已經很用心（8 種變體×3 色、煙、火花、光源），這塊其實是目前最強的。 |
| **後製／調色** | 小～中 | SSAO／SSR 在空曠太空裡本來就幾乎沒東西可遮蔽、可反射，所以「影響不大」是正常的，不是 Godot 不行。真正有用的後製是：調色 LUT、鏡頭光芒（引擎 streak）、動態模糊、熱扭曲——這些還沒做。 |

結論：**過去兩天的力氣多在第 3、4 根柱子，但瓶頸在第 1、2 根。**

### 1.3 流程上的問題
1. **我（Claude）看不到真正的畫面**：雲端只有軟體渲染（llvmpipe），每一次調整都要等你截圖回饋 → 回饋慢、靠感覺。
2. **沒有固定的比對鏡頭與「做完」的標準** → 加了又拿掉（POM 加→拿掉、後製加→拿掉、三艘模型改→還原），每一輪都在重新摸索。
3. **兩條線同時跑**：Godot 版與網頁 v3 交替 build，注意力分散。
4. **`battle.gd` 單檔 2442 行**：玩法、渲染、劇本都在裡面，每加一個效果都容易牽動別處。

## 3. 新做法（路線 A）

### 階段 V0：建立「看得見」的回饋迴圈（先做，約 1 個 session）
目的：每次改動都能在同樣條件下比較，不再靠記憶。
1. **固定鏡頭組**：新增 `-- --lookdev` 模式，自動依序拍 6 個固定畫面（近景艦體側光、艦隊遠景、爆炸近照、光束命中、鐵墓、駕駛艙），存 PNG 到 `user://shots/`，同時記錄每張的 **GPU 毫秒數**（`RenderingServer.viewport_get_measured_render_time_gpu`）。
2. **一鍵批次檔** `godot/tools/lookdev.bat`：你雙擊 → 跑完 → 資料夾自動打開，把整個資料夾拖給我即可。
3. **參考對照板**：每個固定鏡頭配一張 SQ42 參考幀（從你之前的影片挑），寫在 `VISUAL-REFERENCE-SQ42.md`，當「做完」的標準。
4. **效能預算**：1080p／60 fps on RTX 2070S → GPU ≤ 14 ms（留 2 ms 餘裕）。每項新效果都要標出花了幾毫秒。
5. **A/B 規則**：每一項新效果都要有遊戲內開關鍵，**一次只改一個變數**，你在同一個畫面切換比較後再決定留不留。

### 階段 V1：光照基礎（預期是最大的單項提升，約 1~2 個 session）
1. **主光開陰影**：DirectionalLight3D 開 PSSM 陰影，依鏡頭距離調分段（太空尺度大，只讓鏡頭附近 ~數千單位內的艦投影；遠處靠環境光）。艦體 `cast_shadow` 打開（MultiMesh 也可以）。
2. **反射與環境光**：用天空著色器的星雲當反射來源（提高天空的 radiance 品質與更新方式），必要時在戰區中心放 ReflectionProbe；環境光改為「冷藍灰墊底」而不是全域 0.2 平光。
3. **三點光構圖**：主光（暖白、強）＋星雲方向的彩色補光（弱）＋邊光（冷），參數放進資料檔，不寫死。
4. **爆炸光照陰影**：只讓「最近的 1~2 個」爆炸光源開陰影（貴），其他維持無陰影。
5. 驗收：V0 的 6 張圖與參考幀並排，你判斷「立體感／金屬感」有沒有明顯提升。

### 階段 V2：材質與資產（真正的天花板，約 2~3 個 session，需要你參與）
1. **材質資料化**：新增 `godot/data/materials.json`，每艘艦的底色亮度修正（反網頁版提亮）、金屬度、粗糙度、發光強度都在這裡調，不改程式。
2. **補齊 PBR 貼圖**：用 Blender 管線（`tools-src/blender/`）為每艘主力艦烘焙**法線圖**與**金屬度／粗糙度圖**；加上**細節法線**（可重複的面板／鉚釘紋路，近看才出現）取代 POM——便宜而且不僵。
3. **發光細節**：艦窗、航行燈、引擎口的發光貼圖（emissive），這是「大艦有尺度感」的關鍵。
4. **模型本身**：TRIPO 模型的造型與 UV 是硬上限。先挑 **1 艘英雄艦**（建議黑塔或仙舟巡洋艦）做到滿分，當全艦隊的範本；其他艦之後照做。模型的造型修改要你確認方向後才動（避免再次「改了又還原」）。

#### 英雄艦：黑塔空間站（使用者 2026-10-22 決定；參考圖為使用者提供的官方高解析截圖）
驗收時逐項對照：
| 部位 | 參考圖的樣子 | 材質重點 |
|---|---|---|
| 尾端大環＋輻條 | 亮白、厚實的環，內側有面板分割與細縫，輻條細而直 | 白陶瓷：非金屬、粗糙度約 0.35、清漆；面板縫用法線＋AO 烘焙 |
| 前段艦體 | 白色裝甲板層層疊疊，板與板之間有**深色凹槽**，邊緣銳利 | 同上；凹槽要在法線圖／AO 上，主光陰影要能落在凹槽裡 |
| 後段艦體 | **深灰黑**分段，表面有細窗格與白色小標記 | 深灰半金屬（金屬度 0.4~0.6、粗糙度 0.5），窗格做發光貼圖 |
| 飾板 | 少量**橘色**長條飾板與方塊 | 橘色漆面，非金屬 |
| 航行燈 | 艦體各處多個**紅色小點** | 發光貼圖＋泛光 |
| 引擎 | 尾端數道**冰藍色細長光束**向後拉出 | 引擎口發光＋ V3 的引擎光束特效 |
| 天線、太陽能板 | 細長白色天線多支；側邊一片**金色**太陽能板 | 太陽能板：金色金屬、帶格線法線 |
| 光照 | 單一主光從左上，陰影面深但仍見細節（冷色環境光）；背景淡褐色星雲 | V1 已做的主光陰影＋冷色墊底 |

### 階段 V3：特效精修（約 2 個 session）
- 爆炸火球、煙改用 **預渲染 flipbook 貼圖**（Blender 模擬後烘成序列圖），取代純程序式著色器，質感最接近 SQ42。
- 引擎尾焰＋藍白光芒（lens streak）、護盾泡、受損艦持續冒細白煙、飛彈煙跡。
- 熱扭曲（爆炸、引擎後方）。

### 階段 V4：後製與調色（約 1 個 session）
- 使用 Godot 4 的 **Compositor（CompositorEffect）** 寫自訂後製：調色 LUT、橫向鏡頭光芒、輕度色差、動態模糊。
- 調色目標：冷藍灰為主、局部暖色（見 SQ42 參考第 1 節）。

### 階段 V5：畫質檔位定案
- 依 V0 量到的各項毫秒數，重新定 High／Balanced／Low。

**V0＋V1 第一版（第十六版）**
- V0：`--lookdev` 固定種子開局、8 個固定鏡頭、每張左右對照（A 舊光照／B V1），量 GPU／CPU 毫秒；`godot/tools/lookdev.bat` 一鍵執行並開啟 `godot/lookdev_out/`。
- V1：`scripts/lighting.gd`＋`data/lighting.json`。主光 4 段 PSSM 陰影（只有第 2 層＝艦艇／鐵墓／斷片／駕駛艙投影）、天空反射立方體貼圖加主光柔光＋冷色底（看得到的背景不變）、冷藍灰環境光、補光；近處 1~2 盞爆炸光源投影；F5 新舊切換；F4 檔位含陰影。
- 雲端驗證（軟體渲染 llvmpipe，毫秒數無意義）：01~08 鏡頭無腳本錯誤；B 圖可見自身陰影（黑塔尾環、螺絲咕姆月球的格架投影在球面上）、陰影面變深。**實際觀感與效能要在使用者的 RTX 2070S 上跑 lookdev.bat 判斷。**
- 觀察（影響 V2）：目前 `hss.glb` 與參考圖差距很大——造型偏「融化」圓鈍、缺少參考圖中層疊的裝甲板、深色凹槽與銳利邊緣。**光靠貼圖補不回來**，V2 黑塔需要先決定：在 Blender 重建主要造型（先前的 `hss_build.py` 程序式重建曾被退回，需要使用者先看草圖確認方向），或請 TRIPO 依參考圖重拉後再做貼圖。

**Build 17（2026-10-24）**：ESC 設定選單（`battle_ui.gd` 的 PAUSE_SPEC、`battle.gd` 的 opt／apply_settings）、引擎光暈（`glow.gdshader`）、HUD／標題版號；Balanced 預設改為不開陰影，陰影等級由選單決定。使用者要求：Godot 畫質提升版改由 Claude 全權推進，使用者只試玩給回饋。

**Build 18（特效精修）**：`fx_extra.gd`＋`trail/shield/heat.gdshader`——引擎尾焰（軸向公告板長條，隨油門變長）、護盾泡（球殼菲涅耳＋命中漣漪，破盾大漣漪）、受損大艦（HP<65%）與飛彈的持續煙（16 個發射器池，依粒子密度設定縮減）、飛彈尾跡、熱扭曲環（大爆炸／飛彈命中，折射螢幕貼圖）。
