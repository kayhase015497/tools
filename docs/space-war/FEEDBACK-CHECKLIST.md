Build 21 指揮官：Tab 切換是否順手？框選／移動／C／X／T 是否正確？小地圖與指令列位置是否合適？
Build 22：艦載飛彈垂直冷發射兩段點火的觀感、IPC SID 單艘與 55~80 秒重生、HSS 近距離面板細節、滑鼠游標。
Build 23：莫比烏斯環大小／亮度、左右資訊流質感、Space Mono 字型。
Build 24：飛彈發射／點火／命中、護盾破裂、戰機掠過音效的聽感與音量（雲端聽不到）。
Build 25：鐵墓外殼（暗金屬＋紅輪廓光＋裂光）是否太暗／太亮；近看鐵墓的細節是否夠。
Build 26：天空星雲結構的好壞；GPU 是否因此變卡（Low 檔位可關）；藍色星雲是否太搶。
Build 27：太空塵速度感是否自然、是否太明顯或看不到（建議用 Shift 加速觀察）。
效能：各檔位實際 FPS（HUD 右上）、開／關陰影的差異、`godot\tools\lookdev.bat` 的毫秒數。
Build 28~30（規劃）：待實作，見 docs/space-war/AUDIO-VISUAL-PLAN-2.md；音訊批次一次試聽，無法在雲端驗證聽感。
Build 28：劇本語音/電台出現時音樂與音效是否適度壓低、恢復是否自然；大戰時近處爆炸是否不再被吃掉；有無破音（限幅器）。
Build 29：引擎轟鳴音量/音高是否自然（太吵或太像噪音？）、駕駛艙與追尾視角的悶音差異、遠處爆炸延遲是否有臨場感、距離低通是否讓遠處槍聲過悶。
Build 30：加速時視野拉伸是否舒適（太大？暈？）、砲口閃光是否會讓畫面閃爍過頭、被擊中時的色差脈衝是否有感；是否想要命中停頓（hit-stop）。
Build 31：艦隊規模×2 後 FPS 變化（可在 ESC GRAPHICS 調 Fleet size）；仙舟巡洋艦是否看得到；巡洋艦垂發飛彈齊射的觀感與數量；音效同時 160 個後是否還有消失；語音時音樂不壓低是否滿意。
