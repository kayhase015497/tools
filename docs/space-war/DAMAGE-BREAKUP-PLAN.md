# 損傷表現新思路：爆炸後大型艦艇斷裂成數塊，斷面燃燒餘燼

> 2026-10-22。取代先前「裂縫＋熔岩」POM 損傷（太僵硬，已移除）。目標引擎：Godot 4.7（D3D12 + Forward+）。

## 1. 想要的效果（以 Squadron 42 影片為參考）
- 大型艦艇被擊毀時，先有高亮爆炸，**艦體沿結構弱點斷成 3~7 塊**，各塊帶著爆炸的動量緩慢翻滾、分離。
- **斷面（切開的內部）**：粗糙、焦黑的內部結構，凹處**暗紅橘的餘燼光**，隨時間脈動、慢慢熄滅；斷面邊緣有零星火星剝落。
- 每塊斷片拖一條細煙與餘燼；最後化為碎片場，再淡出。
- 同一型號每次斷法不同（亂數），避免重複。

## 2. 技術路線
### A. 預先在 Blender 切好（建議）
每個大型艦艇型號（巡洋艦、IPC 巡洋艦、仙舟無畏艦、黑塔空間站、軍團航母、IPC SID）各做 **3~4 套斷裂方案**，匯出成 GLB：`<ship>_frag_<方案>.glb`。
1. **切塊**：用 Voronoi／平面切割（`bmesh.ops.bisect_plane` 或 Cell Fracture 外掛）沿艦體長軸與橫軸切成 3~7 塊；切面方向帶隨機傾斜，邊界用雜訊擾動，避免筆直。
2. **補斷面**：每塊的切口補上**內部蓋面**（有厚度的內框：加幾道隔板、肋骨、管線簡模，讓斷面不是平的），指定給專用材質槽 `break_face`。
3. **斷面 UV 與高度圖**：斷面用程序式紋理（噪聲＋Voronoi 裂紋）烘出 **高度圖**與**餘燼遮罩**，並走 POM（已完成的 `ship_hull.gdshader` 可直接套用，`burn` 參數控制餘燼）。
4. **錨點**：每塊中心放 Empty `FRAG_n`（質心、初始分離方向、角速度建議值）。
5. **斷面法線朝外、外表保持原貼圖**（原艦體 UV 不變，斷片外表與完整艦完全一致，切換時無縫）。
> 沙盒端工具：`tools-src/blender/space-war/` 已有 bpy 管線；Desktop 的 Blender MCP 可做手動微調（結構弱點位置、斷面細節）。

### B. 遊戲內（Godot）
- 艦艇血量歸零 → 以完整艦的 MultiMesh 實例**隱藏**，在同位置生成該型號的一套斷片（`Node3D` + 每塊 `MeshInstance3D`），套用相同的世界變換與速度。
- 每塊：初速 = 艦速 + 爆炸方向偏移；角速度亂數；以簡單**自寫積分**運動（不用物理引擎，數千艘仍可）。
- 斷面材質 `burn` 從 1 漸降到 0（約 6~8 秒）；餘燼粒子（沿用爆炸系統的 ember 粒子）沿斷面邊緣小量發射；細煙（沿用 smoke 著色器，量少）。
- 預算：同時存在的斷片組有上限（預設 10 組），超過的最舊一組提前淡出；遠處（LOD）的斷片組改成**單一簡化網格**＋ 一個發光 sprite。
- 爆炸與斷裂連動：爆炸變體（現有 8 種）決定斷裂方案與分離速度（噴流＝朝噴流反向；閃爆＝快速分離；悶燒＝緩慢）。

## 3. 資產規模估算
| 型號 | 斷裂方案 | 備註 |
|---|---|---|
| 巡洋艦（仙舟／IPC） | 各 3 套（4~6 塊） | 數量最多，優先 |
| 仙舟無畏艦 | 3 套（5~7 塊） | 大型、慢速斷裂 |
| 軍團航母 | 3 套（5~6 塊） | 配紫色焰 |
| 黑塔空間站 | 2 套（環與艦橋分離） | 劇情型，可手動做 |
| IPC SID | 2 套 | |
| 護衛艦 | 1~2 套（2~3 塊） | 小型，簡化 |
合計約 20~25 個斷裂 GLB，每個 0.3~1 MB（低面數）。

## 4. 建議開發順序
1. **原型（先做一艘）**：巡洋艦 1 套斷裂方案＋ Godot 斷裂播放（斷面餘燼、翻滾、煙），按鍵觸發，驗證觀感與效能。
2. 回饋後，補齊各型號與亂數方案。
3. 接上戰鬥邏輯（血量歸零觸發），與爆炸變體連動。

## 5. 已完成的前置
- 艦體 POM 材質（`shaders/ship_hull.gdshader`）：已含 `INSTANCE_CUSTOM.x`＝燃燒度的餘燼自發光，斷面材質可直接使用。
- 爆炸系統：火球、煙、火花、餘燼、碎片、光源，並含效能預算（可開關）。

## 6. 使用者決定（2026-10-22）
1. 先做**仙舟巡洋艦與 IPC 巡洋艦**。
2. 斷塊**少而大，2~4 塊**，乾脆。
3. 斷面餘燼依陣營：**聯軍橘、軍團紫**。

## 7. 原型進度（已完成）
- `tools-src/blender/space-war/fracture_ships.py`（bpy）：把完整艦沿長軸切成 2／3／4 塊（方案 A／B／C），切面帶亂數傾斜，斷口補蓋並細分＋噪聲位移成凹凸斷面，指定 `break_face` 材質與投影 UV；輸出 `godot/assets/models/frag/{cruiser,ipc}_frag_{A,B,C}.glb`（無貼圖，約 0.8 MB／個，6 個）。
- Godot：`scripts/breakup.gd`——取代完整艦、斷片各自翻滾分離（初速＝艦速＋由艦心向外）、斷面用 POM 材質＋餘燼自發光（1→0，約 7 秒，依陣營橘／紫）、沿斷面飄餘燼粒子；外表沿用完整艦的 POM 材質。按鍵：**U** 仙舟巡洋艦、**I** IPC 巡洋艦（橘色餘燼）、**O** 仙舟巡洋艦紫色餘燼預覽；`-- --break-demo [--purple] [--no-boom] [--close]`。
- 尚未做：細煙尾跡、與爆炸變體連動、接上血量歸零、軍團航母與其他型號的斷裂方案。

## 8. 仍待決定的事

2. 斷塊數量偏好：少而大（3~4 塊，乾脆）還是多而碎（6~7 塊，混亂）？
3. 斷面餘燼色：橘紅（預設），還是依陣營（聯軍橘、軍團紫）？
