# 視覺參考：Squadron 42 艦隊戰（使用者擷取影片 ×2，加速 300%）

> 來源：使用者上傳 `squadron42_1.mp4`（10 秒）、`squadron42_2.mp4`（9 秒）。以每秒 2 格抽幀逐格分析（38 格）。影片已加速，所以下面對「時間」的描述（如火球持續多久）以相對感受為準。
> 用途：Godot 單機版（`godot/`）與網頁版特效的美術基準。**不要照抄素材，只學「效果的構成與光照邏輯」。**

## 1. 太空中的自然光源（整體氣氛的來源）
- **單一強主光**（恆星／行星反光）從一側打來：艦體一面亮、一面幾乎全黑，明暗交界乾脆，金屬面有高光稜線。陰影面不是純黑，而是被**環境色（青灰／藍灰）墊底**，所以細節還看得到。
- **背景有大面積「體積雲」**：土黃／橘棕星雲、青綠星塵、白色雲層行星。它們同時是**背景色塊 + 環境光**：艦船迎向雲的那面會染上對應色調（橘雲旁的船殼帶暖色邊光；行星旁帶冷白邊光）。
- **整體色溫是「冷藍灰 + 局部暖光」**：大面積是低飽和冷色，暖色（橘紅爆炸、引擎）只出現在局部，所以暖色一出現就非常搶眼。這是「畫面很有層次」的主因。
- **空氣透視**：遠處艦隊變小、變灰、變藍，近處對比強。星雲像薄霧一樣讓遠景降低對比。
- 引擎光是**冷藍白**（大型圓形噴口，帶長條藍色鏡頭光暈／橫向光芒 lens streak），反物質軍團用**紅色**發光點（紅色艦燈、紅色光束）。

## 2. 爆炸：多層、不對稱、帶火球內部紋理
一次艦艇爆炸由下列層次疊成（逐格觀察到的順序）：
1. **起爆閃光**：先是極亮的白熱核心＋光暈（帶輕微鏡頭光斑與星芒），非常短。
2. **球狀火團**：橘黃火焰，**表面有「泡泡狀／顆粒狀」的翻滾紋理**（不是平滑的球），內部較亮、邊緣偏橘紅；同一艘船上會在不同位置**連續冒出多個小火團**（不是單一大爆炸），像內部彈藥逐個殉爆。
3. **火花雨**：大量細長火花（橘黃、偏紫的白熱）向外放射，**速度差很大**，有的拖長成線；爆炸中心附近密度最高。
4. **碎片**：黑色碎片、裝甲板、小零件，**剪影清楚**（逆著火光），緩慢翻滾；被火光照到的邊緣有暖色高光。
5. **濃煙（重點）**：爆炸後留下**黑／深灰褐色煙團**，邊緣被火光染成橘色、被背景雲染色；大團、厚重、**有體積與層次（亮邊 + 暗心）**；船艦帶著黑煙長尾移動時，煙是**一條連續、被拉長的軌跡**。受損艦會持續**冒出白灰色細煙**（像剛才被擊中的那艘船後方一條彎曲的淺色煙跡）。
6. **衝擊光環／冷光**：偶爾有藍白色的冷光爆（護盾或能量爆），和橘色火球並存，形成冷暖對比。

## 3. 爆炸火光對金屬的照明（最值得複製的部分）
- **火球是真實的點光源**：爆炸瞬間，附近艦體的金屬面立刻被**暖橘色打亮**，而且是**有方向性的**——朝向火球的那一面亮、背面維持冷灰；高光（specular）在裝甲稜線上拉出一條亮線。
- 火光強度隨距離衰減，**大約半個船身長以內才明顯**，更遠的船幾乎不受影響（所以畫面不是「全部一起變橘」）。
- 火光持續時間短（約 0.3~0.8 秒的強光，之後隨火團縮小衰減），但**火團本身（自發光）在煙裡會停留更久**，煙的底部被持續染橘。
- 火花、碎片自身也發光或受光，所以火光周圍有一圈「閃爍的小亮點」。
- 受損艦體還有**暗紅色的內部發光裂縫／熔融孔洞**（艦殼被燒穿後透出橘紅色光），和外部光源分開。

## 4. 光束與命中（延續先前的電焊參考）
- 光束細、核心白、外暈有色（粉紅／紅），命中點小亮、周圍大量火花片；船殼受擊處會**冒出黑色燒焦痕與碎屑**。

## 5. 飛彈與曳光
- 飛彈有**實體彈身**，尾部一束短而尖的橘白火焰，後面拖**細長淺灰煙跡**（慢慢擴散、略彎曲）。
- 機砲彈是**一串串橘黃色的短曳光點**（像虛線），不是連續光柱；遠景的曳光只是微小橘點。

## 6. 對 Godot 版的落地建議（待階段 1 驗證後排程）
| 效果 | 做法（Godot 4.7，D3D12 + Forward+） |
|---|---|
| 主光 + 環境色墊底 | 一盞 DirectionalLight3D（含陰影）＋ 天空盒／ReflectionProbe 提供冷色環境光，不要純黑陰影 |
| 星雲兼環境光 | 天空著色器分區上色；艦隊附近放低強度彩色 OmniLight3D／Environment 的天空光，讓船殼吃到雲的色調 |
| 爆炸火球 | GPUParticles3D（翻滾紋理的火球貼圖＋噪聲 flipbook）＋ 多個小火團錯時冒出；火球生成時同時放一盞**短命 OmniLight3D**（暖橘、強度快速衰減、範圍約船長一半） |
| 火花與碎片 | 火花：拉長的 additive 粒子（速度差大、有阻尼）；碎片：**剪影清楚的小網格** MultiMesh（受光、慢速翻滾） |
| 濃煙 | 體積霧（FogVolume）或 GPUParticles3D 大面積軟粒子；顏色以黑褐為主，邊緣用「受光」染橘（粒子著色器讀取附近爆炸光強） |
| 受損艦體 | 損傷貼圖＋自發光裂縫（隨血量淡入）；冒細煙的 GPUParticles3D 掛在傷口位置 |
| 引擎光暈 | 長條橫向 lens streak（後處理或獨立 additive quad） |
| 色調 | 冷藍灰為主、局部暖色；ACES 色調映射；輕度 Bloom；對比略高 |

> 預期效能考量（RTX 2070 Super 8GB）：爆炸的光源與體積煙要**限量**（同時只有 N 個短命光源、煙粒子總量設上限），遠距離爆炸降級成單一 sprite。

## 7. 進階觀察（第二輪：放大逐格看細節）

**爆炸火球的細節**
- 火球不是一顆平滑的球，而是**花椰菜狀的「泡泡團」**：中心黃白過曝、外圍橘黃、邊緣紅橘，表面有明顯的顆粒與縫隙（像許多小火球擠在一起）。同一艘船同時有 **3~5 團**，大小不一、錯時冒出，艦體被它們從內部「掏空」。
- 每個火團周圍有一圈**很大的柔光暈（Bloom／Glow）**，光暈裡可見**橫向階梯狀的條紋**（鏡頭 ghosting／變形鏡頭光學感）。火團最亮時整個畫面的白點被推過曝，露出光暈形狀。
- 近距離的爆炸會讓**整個背景染上米黃色**（爆炸補光／相機曝光被拉動），遠景艦影變成剪影；爆炸過後再慢慢回到冷藍灰——**色調的暫時偏移**本身就是演出。

**濃煙（重點）**
- 傷口冒出的是**黑灰色的「花椰菜雲」**：一團團圓鼓鼓的煙球疊在一起，有明暗（頂部受光灰、底部近黑），**內部藏著紅橘色的餘燼光點**（像煤炭透光）。
- 爆炸後的大煙團是**棕黑＋暖黃**：背光時邊緣被爆炸或星雲染成金黃，中心近黑，煙與背景星雲融在一起（所以辨識不出邊界、很有體積感）。
- 煙是**被火光「照亮」而不是自己發光**：火球靠近的那一面偏橘，離火球遠的一面偏冷灰；火團熄滅後，煙的橘色也跟著褪去。
- 受損艦船尾部拖著**一條細長、略彎的淺灰煙跡**（像噴射機凝結尾），而不是粗黑煙。

**碎片與火花**
- 碎片是**成百上千片黑色的三角／不規則薄片**，大小差很多，緩慢翻滾，**逆光剪影**非常清楚；少數被火光照到邊緣發亮。碎片同時提供了「空間深度」與「速度感」。
- 火花有**兩種色系**：橘黃（燃燒金屬）和**粉紫／藍白**（能量武器、電弧），兩種同時出現；多數是短的拉長亮點，近鏡頭的火花會**放大並失焦**（景深模糊）。
- 場景中**始終漂浮著細小的塵埃／餘燼亮點**，鏡頭移動時產生視差，這是「太空不空」的關鍵。

**金屬艦體與損傷**
- 艦體金屬是**中粗糙度的深灰金屬**，細節密度很高（面板線、管線、散熱格柵），受光稜線有銳利的高光。
- **受損處有「熔岩」般的暗紅發光裂縫與孔洞**（像燒紅的煤），平時是暗紅微光、被擊中時變亮；這是自發光貼圖／損傷貼圖，不是外部光。
- 引擎是**成排的大型冷藍白圓形噴口**，各自在附近艦體上打出一圈藍色光池；整艘船因此「被自己的引擎照亮」。
- 艦燈：我方有**綠色／白色航行燈**，敵方是**紅色小燈**（散佈在黑色艦體上），遠看就是黑影上的紅點。

**鏡頭與後處理**
- **強景深**（前景、背景失焦）、**動態模糊**（快速移動的飛彈、碎片拉成條）、輕微**暗角**、**鏡頭光斑**（引擎、火球），畫面帶有電影級的顆粒與輕微色偏。
- 鏡頭是**動態攝影機**：緩慢推進、搖晃，並在爆炸時被「衝擊震動」；剪輯節奏快（每 1~2 秒換鏡頭）。
- 遠景艦隊：成群小剪影，被星雲與薄霧淡化，閃著微小的橘色曳光點（遠距離機砲）。

**指揮介面（影片 2 結尾，可用於單機版指揮官模式）**
- 圓形**全息戰術沙盤**：藍色線框艦艇（友軍）＋橘紅色艦影（敵軍），玻璃半球罩、地面圓盤刻度與方位線、被選取單位周圍有瞄準環與編號。整體是**藍／橘紅對比的線框全息風**，與我們的指揮官介面可以對應。

## 8. 給單機版的優先順序（建議）
1. **光照模型**：先把「單一強主光 + 冷色環境墊底 + 暖色局部光」做對（影響所有畫面）。
2. **爆炸三件套**：花椰菜火球（flipbook）＋短命暖光源＋逆光碎片剪影。
3. **濃煙**：花椰菜煙球、餘燼光點、被火光染色（粒子著色器吃附近光強）。
4. **後處理**：景深、動態模糊、Bloom 光暈、鏡頭光斑、爆炸時的曝光／色調偏移。
5. **損傷表現**：熔岩裂縫自發光、持續冒煙。
6. **細節層**：漂浮塵埃、遠景艦隊剪影與機砲曳光、戰術沙盤介面。
