# Space War Native — 階段 1 驗證小專案（Godot 4.7）

只有畫面、沒有玩法。目的是在 **Windows / D3D12 / Forward+** 上確認：艦艇 GLB 的材質光照、大量艦艇幀數、光束＋電焊火花、泛光／體積霧／調色，是否明顯勝過網頁版。

## 在你的電腦上執行
1. 下載 Godot **4.7（Standard 版，不是 .NET）**：https://godotengine.org/download/windows/ ，解壓縮後直接執行 `Godot_v4.7-stable_win64.exe`。
2. 專案管理員 → Import → 選這個 repo 的 `godot/project.godot` → 開啟（第一次會花一些時間匯入 GLB）。
3. 按 **F5** 執行。右上角標題列／左上角 HUD 會顯示顯卡名稱與 FPS。
4. 確認使用的是 D3D12：專案設定已指定 `rendering_device/driver.windows = d3d12`，HUD 第一行會顯示顯卡。

## 操作
| 鍵 | 功能 |
|---|---|
| 右鍵＋滑鼠 | 轉動視角 |
| W A S D / Q E | 前後左右／下上 |
| Shift | 加速 |
| PageUp / PageDown（或 `]` `[`） | 艦隊數量 ×2／÷2（×1 ≈ 網頁版開場兵力，最高 ×64） |
| M | 讓艦艇移動（在 GDScript 端逐艘更新，量 CPU 成本；正式版會改用 C#） |
| F3 | 3D 解析度縮放 100% ⇄ 75% |
| F2 | 把 FPS 紀錄存到 `user://bench.csv`（HUD 不顯示路徑，在終端機／輸出視窗會印出） |

## 自動壓力測試
命令列：`Godot_v4.7-stable_win64.exe --path godot -- --benchmark`
依序量 ×1、×2、×4、×8、×16 艦隊，每段 10 秒，結果寫入 `user://bench.csv`（Windows：`%APPDATA%\Godot\app_userdata\Space War Native (Spike)\bench.csv`），完成後自動關閉。

## 資料夾
- `assets/models/`：由 `tools-src/godot/sync_models.sh` 從網頁版同步的 GLB（含鐵墓）。
- `shaders/`：天空（星點＋星雲）、光束。
- `scripts/spike.gd`：整個驗證場景（全程用程式建立，方便在雲端無頭驗證）。

## 引擎版本
- 目前以 **Godot 4.7 穩定版**為準（雲端已用 4.6／4.7／4.8-beta1 三個版本驗證：匯入、執行、軟體渲染畫面都正常，專案不需要修改）。
- Godot **4.8 目前只有 beta**（4.8-beta1）：可以試，但正式開發建議等 4.8 穩定版再升級（升級方式：換成新版執行檔開啟同一個專案，把 `project.godot` 的 `config/features` 版本號改成 4.8 即可）。
- 之後要寫玩法模擬時需要 **.NET 版**（C#）；那時再下載 .NET 版 Godot，並新增 C# 專案檔。

## 爆炸展示牆
命令列加上 `-- --explode-gallery`：在鏡頭前排出 3 列（橘色／紫色／先橘後紫）× 8 欄（8 種變體）的爆炸，方便比較。平常遊玩時，每次爆炸會從 8 種變體中亂數挑一種，並對顏色、尺寸做小幅亂數。

## 艦體損傷（POM）
- 按 **K**：全艦隊損傷度循環 0 → 0.35 → 0.7 → 1.0 → 0；或命令列 `-- --damage-demo` 直接貼近一艘巡洋艦看損傷度 0.85。
- 效果：程序式裂縫＋燒蝕坑（Voronoi 裂縫線與噪聲坑）用**視差遮蔽貼圖（POM）**讓裂縫真的凹進去，視角改變有視差；凹陷處露出會脈動的熔岩橘光、周圍焦黑、粗糙度上升；受損艦的艦燈閃爍。遠於 2600 單位自動略過 POM，只留廉價焦黑。
- 備註：Godot 沒有硬體曲面細分（Tessellation）著色器，所以用 POM；若日後要真實幾何位移，可改高面數網格＋頂點位移。

## 艦體材質（POM 全面升級）與開關
- 艦艇底色貼圖都配了**高度圖**與**粗糙度圖**（由 `tools-src/godot/make_heightmaps.py` 從底色推導；面板接縫、凹槽在高度圖上是凹的）。`shaders/ship_hull.gdshader` 用視差遮蔽貼圖（POM）讓它們真的凹進去，視角改變有視差與遮擋；另有凹處髒汙、凸緣磨亮、高度場法線擾動、凹槽自遮蔭。POM 層數隨距離遞減，遠於 3200 單位略過。
- **K**：POM 開／關（比較升級前後）；`-- --hull-demo`（可加 `--no-pom`）貼近一艘巡洋艦看材質。
- **P**：爆炸效能保護開／關，**預設關閉**（想要大混戰更混亂）。

## 艦艇斷裂原型
按 **U**（仙舟巡洋艦）／**I**（IPC 巡洋艦）：鏡頭正前方最近的一艘巡洋艦爆炸並斷成 2~4 塊（隨機方案），斷面有燃燒餘燼（橘色）；**O**：紫色餘燼預覽。命令列 `-- --break-demo [--purple] [--no-boom] [--close]` 自動示範。斷片由 `tools-src/blender/space-war/fracture_ships.py` 產生。詳見 `docs/space-war/DAMAGE-BREAKUP-PLAN.md`。

## 後製、戰鬥與斷裂（第十一版）
- **T**：DX12 後製開關（SSAO／SSIL／SSR、近景景深、顆粒＋暗角；`-- --no-post` 啟動即關）。遠景不做景深（會把天空星點糊成大光斑）。曝光降到 0.82、主光 0.95，改善艦體過曝。
- **H**：戰鬥開關。聯軍光束打軍團母艦、軍團光束打聯軍，持續照射造成傷害；血量低於 35% 的艦會冒小爆炸；歸零 → 斷裂（仙舟巡洋艦、IPC 巡洋艦、軍團母艦、黑塔、IPC 旗艦、護衛艦有預切斷片）或爆炸（戰機）。聯軍橘色餘燼、軍團紫色。`-- --combat --timescale=8` 可開機即戰並加速。
- **G**：鏡頭正前方最近的艦血量直接歸零（測試串接）。
- 血量：巡洋艦／IPC 120、護衛艦 50、戰機 15、軍團母艦 150、IPC 旗艦 150、黑塔 600；仙舟無畏艦（xzd）不可摧毀。
